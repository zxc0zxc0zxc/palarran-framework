# Frozen eval suite поверх существующего runtime

## Контекст и основание

Пользователь просит /agent:eval, документацию прежде реализации, независимую оценку качества/расхода/времени; tests без paid runs. Existing leases/accounting/context/final gates пригодны для reuse.

## Выбор и объяснение

Отдельный suite compiler и report/compare CLI используют engine.create/work/status без второй системы учёта. Frozen private bundle, pinned external command graders либо exact JSON checks, stable final rechecks и subject fingerprint. Serial fail-fast/max_attempts=1 сохраняют общий budget; AI policies обязательны без default нового лимита. work требует отдельный explicit model flag. Fixture pass не model quality. PASS только на final verified subject; unknown/drift/infrastructure = inconclusive, never zero cost.

## Альтернативы

Self-report grader отвергнут: агент не доказывает собственное качество. Paid LLM judge/автороутинг и массовые trials не входят в первый scope. Отдельный scheduler/SQLite ledger дублировал бы recovery/accounting. Container isolation полезна для hostile candidates, но текущий v1 использует только trusted fixtures/process bounds и явно не обещает sandbox.

## Источники и evidence

Primary dated sources: docs/agent/eval/sources.md (Anthropic 2026-01-09, 2026-02-05; SWE-bench rolling guide checked 2026-10-23). Source applicability и пределы — methodology.md. Existing runtime source/contracts проверены до edits.

## Последствия и пересмотр

Не все свойства плана оцениваются JSON equality; custom tests/rubric review обязательны по задаче. Отчёт показывает skipped denominator и все расходы. Multi-run shared budget переносится явно через carry, автоматических trials нет. Пересмотр после separately authorized real trials, а не после synthetic smoke.
