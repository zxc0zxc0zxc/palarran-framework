# Реальная подготовка и fail-closed gate

## Контекст и основание

Пользователь разрешил реализацию подготовки данных в ML pipeline и offline tests без платных запусков. Model/data downloads и cloud execution не входят в задачу.

## Выбор и объяснение

1. Optional frozen data_preparation policy добавляет отдельный bounded command ml-prepare после benchmark planning. Existing exact-prefix approval требуется до подготовки; исходники/config/tokenizer/executable pins входят в context. Gate до reservation и повторно перед fit/evaluate проверяет stable receipt. Старые non-text workflows совместимы, их status явно not_configured; это не PASS data gate.
2. Реальный HF tokenizers из local tokenizer.json, без Hub, truncation и автоматической установки; literal role template ограниченного формата, offset-based masks и собственный right-padding collator/unshifted labels. Unsupported layouts/ambiguous boundaries/UNK/overflow отвергаются. Версия library pinned; tiny tokenizer обучается локально только для offline tests. Optional dependency устанавливается отдельно в temporary development environment, никогда из runtime/tests.
3. Whole-example deterministic mixture без обрезки: integer per-record repeat ceiling floor(max_repeats), никаких holdout rows, actual domain/language floors и явный tolerance по token shares. Недостижимые quotas блокируются, не нормализуются молча. Независимый verifier повторяет подготовку/токенизацию/collation и сравнивает bytes/digests, вместо доверия JSON PASS. Финальный receipt связан с source и launch policy.
4. Первая версия поддерживает local text execution. Modal text preparation отвергается до создания run: remote Volume transport/verification требует отдельного контракта; существующий Modal non-text pipeline сохраняется. Не выдаём host audit за доказательство remote consumption.

## Альтернативы

Producer complete=true недостаточен. Transformers/torch и произвольные Jinja templates дают лишние dependencies и не нужны bounded adapter. Невозможно универсально выбрать model-native template: explicit reviewed literal layout и tokenizer pins — необходимое входное условие. Не добавляем скрытый cloud upload или paid test.

## Последствия и пересмотр

Template только system/user/assistant, unpacked, text-only; no tool/multimodal/packing. Semantic completeness, language truth, near contamination и post-training general regression требуют отдельных reviews/benchmarks. Максимумы source/output/records/sequence/batches обязательны; local CPU использует wall-time run budget, не fictitious provider USD. Бюджет AI/GPU не увеличивается. Пересмотр при remote transport или новом model-native template.
