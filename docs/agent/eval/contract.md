# Suite v1

JSON <=1 MiB; duplicate keys, NaN, symlinks и escaping paths запрещены. Поля: version=1, id, revision, candidate (короткие IDs), limits, policy, cases; опционально ai_policy/usage_policy по existing runtime contracts. Cases 1..100: id, category (plan/build/review/context), task, checks. Task — обычный runtime task без id/verify/dependencies/retry fields; adapter command для fixtures либо codex/claude с prompt/executable/model_role/model_calls. context/transport разрешены по runtime. AI требует обе policies; никакой default денежной квоты не выделяется. Cases исполняются последовательно без retry. limits.max_attempts обязан быть 1.

Checks 1..20:

- json_equals: kind, path (target-relative regular JSON <=64 KiB), expected (JSON value); сравнение типов строгое, bool не number. Формат/путь явно включить в task prompt.
- command: kind, argv (explicit absolute allowlisted executable), pins (непустой список абсолютных external regular files). Все interpreter scripts/fixtures/config/resources grader перечислить в pins. argv не shell; {workspace} заменяется на exact owned worktree. Pins не могут находиться в target/state candidate workspace. Scripts/fixtures должны быть самодостаточны; verifier dependencies вне pins — ограничение доверенной конфигурации.

create нормализует manifest, hashes pins и harness source, сохраняет private bundle вне worktree; generated verifier argv содержит bundle SHA. Runtime workflow snapshot фиксирует argv и budget. Bundle/checker drift приводит к fail-closed. Не читать .env/credentials/raw logs как eval input. Public reports содержат метрики и hashes, не prompts/ожидаемые ответы/stdout. Drift при чтении report отклоняется с безопасной ошибкой; такой результат нельзя считать PASS. Private bundle содержит rubric, его нельзя коммитить.

report читает только bound run и проверяет workflow digest, suite/pin/harness hashes, final subject, usage completeness; JSON output hashes сверяются со stable receipts даже для Git-ignored answers, без повторного исполнения command graders. Отдельный quality_verdict отражает финальные проверки; overall verdict дополнительно требует полного финансового учёта. Исторический unknown carry не обнуляет уже доказанное качество, но запрещает вывод о полной стоимости/экономии. Показывает кейсы, попытки/измеренные seconds, runtime reason, PASS/FAIL/INCONCLUSIVE/NOT_RUN, pass_count/total_cases/coverage, cumulative usage включая carry и observed lower bounds. Финально непроверенная suite не получает PASS. command-only sample_kind=fixture, tokens/cost=null (нет model measurement); zero spend не доказательство model efficiency.

compare требует одинаковый protocol_sha256 (входы/prompts/graders/лимиты/ценовые и token budgets), harness hash, baseline, environment и фактически переданный context; различаться могут candidate label и assigned model/effort/executable. Повторное сравнение одного run с самим собой запрещено. Незавершённые/fixture runs не дают model cost savings. Изменение skill prompt — новый protocol, сравнение вручную с явным описанием различий. Auto routing и paid judge не входят в v1.
