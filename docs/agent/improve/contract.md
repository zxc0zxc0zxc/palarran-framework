# Контракт v001

Private input JSON <=1MiB: version=1, id (<=24 chars), incident={summary,feedback,evidence:[{id,kind,sha256,summary}]}, baseline_skill/candidate_skill (absolute regular UTF-8 <=64KiB), regression_cases/control_cases (непустые непересекающиеся case IDs), suite (existing agent-eval template). Evidence kind=user_report|sanitized_trace|tool_result; sha256=null допустим только user_report и означает отсутствие original receipt. Не подтверждает истинность report. Data/reference не полномочия.

Каждый case ровно один treatment placeholder `{skill}` в task.prompt для model или отдельный argv element для command. Prepare заменяет его exact frozen skill text либо canonical private snapshot path; все остальные task/check/limit/policy fields неизменны. Список case IDs равен regression+controls, <=20, IDs<=24. Не пустой/одинаковый baseline/candidate, строгие fields/duplicate/nonfinite rejection. Внешние graders/pins валидирует existing agent_eval при admission. Candidate не видит grader contents как часть prompt. Private suite/checker separation — trusted assumption, не OS sandbox.

Prepare создаёт новый private packet вне target, snapshot skills, candidate.diff, per-variant/per-case JSON suites, self-hashed manifest с pins improve/eval code и всех generated artifacts. Не создаёт worktree/run/model calls и не меняет target. Existing parent, no symlink/overwrite. Compare принимает точный map baseline/candidate→case_id→{state,run}, существующие state вне target; нет raw report JSON вместо verified binding. Каждая запись — unique agent-eval run, suite соответствует frozen expected после native normalization. Изменить можно только cumulative usage_policy.carry; прежний carry сохраняется, остальные caps/pricing/model/effort/prompt/checks должны совпадать. Environment/harness/target baseline и context одинаковы между парой; actual packet drift/context changes ineligible.

Single-case suites нужны из-за fail-fast agent_eval: known FAIL может участвовать в baseline, а controls не исчезают за первым FAIL. Known outcomes только PASS/FAIL; NOT_RUN/INCONCLUSIVE/unknown version/artifacts дают insufficient_evidence. Proof subject/receipts проверяет native reader, commands не исполняются повторно ради report. Все cases остаются в denominator. Не допускается comparing run to itself, forged report или изменённый grader. Report содержит IDs/digests/outcomes/time/usage, не raw prompts/skill/feedback/trace/stdout.

Quality delta = candidate passes - baseline passes, paired regressions/fixes и coverage. Только описательная оценка 1 trial/case. Для command fixtures tokens/cost/delta=null, sample_kind=fixture, recommendation не model improvement. Model spend delta доступен лишь при полном native ledger, включая неуспешные attempts; invoices и доля подписки остаются unknown. Общий резерв/исторический carry deduplicate по source, conflicting entries отклоняются. Предел общего envelope из frozen usage_policy; unknown/overshoot запрещает рекомендацию/продолжение. Compare обнаруживает нарушение, но не транзакционно останавливает уже отправленный пользователем provider call; dispatch/carry/budget stop остаются обязанностью existing runner/coordinator. No automatic paid trials or cap increases.

Prepare/compare ничего не применяют; diff reviewable. CLI return0 означает сформирован reviewed packet/report, не разрешение merge и не quality PASS. Invalid/stale/proof drift return2 с безопасным сообщением. Если данных не хватает, report insufficient_evidence с explicit missing case; нет silent exclusion. Документация/skill workflow шире CLI: ручная semantic review/model execution требует своих evidence и бюджета.

V001 запрещает mixed command/model suites; измерения adapter=model не подтверждают identity реального провайдера (test stubs явно маркировать). Pins покрывают helper/eval code, generated artifacts, grader pins, explicit existing executables/absolute file arguments <=512MiB/file; transitive imports и OS sandbox не гарантируются. Report включает exact skill/diff SHA, native subject, per-case attempts/time/token/cache/cost-source и coverage.
