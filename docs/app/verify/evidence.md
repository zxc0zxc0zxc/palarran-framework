# Evidence, defects and privacy

Reports bind suite/protocol digest, source files/revision, live identity before/after, run/entity correlation, actual browser engine/version/runtime pins, case/R-ID, step outcome/seconds, required/missing/N/A surfaces and artifact hashes. Verdict covers executed scope only. JSON/MD summaries contain no response bodies, DB rows, console text, credentials/cookies/env dumps. Internal exceptions expose enum/class only, never str(exception) with URLs/PII.

Screenshots are opt-in with fixed viewport, private local file and SHA. Captured != viewed != approved; an external human/agent must actually open the image and record review subject/limits. V1 has no automatic aesthetic grader and writes no trace.zip/auth state. Existing Playwright traces require a specifically authorized private workflow and privacy review, with no public upload.

A report-artifact hash is a consistency receipt, not an independent notary signature. Trusted evaluator/suite separation are assumptions. Public defect cards include minimal sanitized repro/predicates and private evidence references instead of raw customer content. Model/skill-quality evaluation and product business validation remain separate from deterministic fixture/browser assertions.

Cancel/crash/timeout preserves intent/partial report; unknown mutation never means “nothing happened.” Do not replay that run. Operators inspect actual effects/current environment before another scenario. Source/artifact tampering makes a report stale/INCONCLUSIVE; never rerun merely to read it.
