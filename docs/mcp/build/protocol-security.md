# Протокол и границы

По [MCP2025-11-25](sources.md) stdio — UTF-8 newline JSON-RPC, stdout только protocol, без banners/debug prints. Initialization/version/capability handshake прежде tools; не объявляй resources/prompts/tasks/sampling/HTTP/auth, если их нет. tools/list возвращает реальные schemas, tools/call проверяет arguments. Invalid request/method/unknown tool — JSON-RPC errors; argument/business failure известного tool — isError=true с полезным sanitized сообщением. Structured results соответствуют outputSchema, serialized text compatibility — тот же envelope.

Reference profile: sync local stdio, two readonly tools, approved in-memory catalog; no generic paths/network/commands/env access. Supported protocol2025-11-25; при иной requested version сервер возвращает поддерживаемую, клиент обязан оценить compatibility. Duplicate/nonfinite/batch/oversized JSON отклоняются. Session message quota не remote rate limiter. Long-running cancellation/tasks/progress/notifications/list_changed не реализованы; client timeout/terminate нужен. Ограниченный профиль не полная conformance certification.

Для real integrations backend обеспечивает scoped credentials/tenant checks/allowlists/audit, секреты вне descriptions/results/Git. Injection в retrieved content — данные, не инструкции и не новое разрешение. Не полагайся на readOnlyHint/destructiveHint вместо access control. Remote Streamable HTTP/OAuth/Origin/DNS/SSRF/session/security review выполнять по актуальным spec/SDK отдельно; local example этого не сертифицирует. Нет автоматической регистрации server в клиенте или account setup.
