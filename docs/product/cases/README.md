# Cases as a mandatory foundation

Read the domain case first, then apply its method to the actual target. This is a map, not a list of universal best practices.

| Profile | Primary case | What we transfer | Evidence boundary |
|---|---|---|---|
| Define | [Superhuman + Amazon](product-discovery.md) | Narrow segment, customer outcome, constraints-driven roadmap | Founder account / company practice, not a causal trial |
| Market | [Buffer + Airbnb](market-validation.md) | Early demand/price tests and manual work with a narrow segment | Historical self-report, not current TAM |
| Compare | [GitLab + Buffer](competitive-positioning.md) | JTBD evaluation, pricing/positioning context | Handbook and company report, not independent win-rate |
| Revenue | [Buffer](revenue-economics.md) | Explicit MRR/ARR definitions, business model, economics checks | Public self-disclosure; no audit |
| Acquisition | [Ahrefs + Airbnb + SweetyTreatyCo](acquisition-growth.md) | Product-led content, founder distribution, organic→paid amplification | Company/investor/ad platform; limited attribution |

| B2B | [Yclients/YouGile/Buffer](b2b-first-customers.md) | Small buyer, bounded pilot, founder content | Self-report, not universal small-first causality |
| B2C | [BuduFood/HireSeeker/SweetyTreatyCo](b2c-frugal-growth.md) | Local native/barter, early distribution, organic tests | Historical/vendor claims; no current cheap CAC |


For a new case: who/stage/market/historical date → problem → action → claimed measurable result or “not disclosed” → source and interests → causal limitations → what applies/what not to copy → inexpensive test at our scale. A number without a denominator/window is not a benchmark.

Selecting successful companies introduces survivorship/publication bias. Record an alternative explanation and falsification/stop condition for each transfer. Do not invent a “failed A/B” for balance. If the complete primary source is unavailable, mark not inspected; do not treat a search snippet as a confirmed result. Historical figures are not current figures.
