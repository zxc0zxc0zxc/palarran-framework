# Кейсы как обязательная основа

Сначала прочитать профильный кейс, затем применять метод к actual target. Ниже карта, не список универсальных best practices.

| Профиль | Primary case | Что переносим | Evidence boundary |
|---|---|---|---|
| Define | [Superhuman + Amazon](product-discovery.md) | Узкий сегмент, customer outcome, roadmap от ограничений | Founder account / company practice, не causal trial |
| Market | [Buffer + Airbnb](market-validation.md) | Ранние проверки спроса/цены и ручная работа с узким сегментом | Исторический self-report, не современный TAM |
| Compare | [GitLab + Buffer](competitive-positioning.md) | JTBD evaluation, контекст pricing/позиционирования | Handbook и company report, не независимый win-rate |
| Revenue | [Buffer](revenue-economics.md) | Explicit MRR/ARR definitions, business model, проверка economics | Public self-disclosure; audit отсутствует |
| Acquisition | [Ahrefs + Airbnb + SweetyTreatyCo](acquisition-growth.md) | Product-led content, founder distribution, organic→paid amplification | Компания/инвестор/рекламная площадка; attribution ограничена |

| B2B | [Yclients/YouGile/Buffer](b2b-first-customers.md) | Small buyer, bounded pilot, founder content | Self-report, не универсальная small-first причинность |
| B2C | [BuduFood/HireSeeker/SweetyTreatyCo](b2c-frugal-growth.md) | Local native/barter, early distribution, organic tests | Historical/vendor claims; нет текущего дешёвого CAC |


Для нового кейса: кто/стадия/рынок/историческая дата → проблема → действие → заявленный измеримый результат или «не раскрыт» → источник и заинтересованность → causal limitations → что применимо/что не копировать → дешёвая проверка на нашем масштабе. Число без denominator/window не становится benchmark.

Выбор успешных компаний имеет survivorship/publication bias. Поэтому для каждого переноса записать альтернативное объяснение и falsification/stop condition. Не придумывать «неудачный A/B» для баланса. Если полного первоисточника нет, отметить not inspected, не использовать поисковый snippet как подтверждённый результат. Исторические цифры не представлять актуальными.
