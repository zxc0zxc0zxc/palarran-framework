# Источники данных и API: conditional access

Case-based methods обязательны прежде инструментов: [case map](cases/README.md). Проверено 2026-10-19; **ни один account/API не подключён этим пакетом**. Использовать реально доступные host connectors/tools или разрешённый web/manual export; SDK endpoints не изобретать. Catalog описывает возможность, а не установленный integration.

| Provider / source | Данные и применимость | Доступ / ограничения / fallback |
|---|---|---|
| [Google Trends API alpha](https://developers.google.com/search/apis/trends) | Search interest, rolling 5y, consistent scaling, geography | Заявка/approval, не общедоступный API key. Проверить реальный доступ; иначе Trends UI/export, явно записать другой measurement contract |
| [Trends UI](https://support.google.com/trends/answer/4365533?hl=en) | Relative sampled index | Export доступными средствами; хранить query/window/geo/property. Не переводить индекс в покупателей |
| [Google Ads Keyword Planning](https://developers.google.com/google-ads/api/docs/keyword-planning/overview) | Historical volume/competition/bid metrics; это не чужой spend | OAuth/account permissions и Cloud project access, актуальная версия API; stricter quotas/cache. [Current access migration](https://developers.google.com/google-ads/api/docs/api-policy/developer-token): developer tokens sunset с 2026-09-09, не копировать старый onboarding; library compatibility проверить. Без доступа official export/public research |
| [Meta Ad Library API](https://br-fr.facebook.com/ads/library/api/?source=onboarding) | Доступный архив, creatives/delivery; поля зависят от категории/региона | На проверенную дату all-type UK/EU за год, worldwide political/social ads за 7 лет; auth/identity requirements. Spend ranges из political ads нельзя приписывать всем commercial ads. API scope отдельно от public UI |
| [TikTok Commercial Content API](https://developers.tiktok.com/products/commercial-content-api) | Advertiser/paid ads/selected commercial metadata | Application approval, client auth; текущая страница указывает EU-only data, global requester eligibility. Ads до года после last shown. Не обещать глобальный полный архив |
| [TikTok Creative Center](https://ads.tiktok.com/business/library/NA_Creative_Center_Top_Ads_One_Pager.pdf) | Selected high-performing creatives, вдохновение | Curated selection, не census всех competitor ads, budget или гарантии ROAS |
| [Google Ads Transparency](https://blog.google/innovation-and-ai/technology/ads/announcing-the-launch-of-the-new-Ads-Transparency-Center/) | Public advertiser/ad research | UI observation; общедоступный универсальный API здесь не подтверждён, не обещать готовый collector |
| [Similarweb](https://docs.similarweb.com/api-v5/similarweb-api/website-analysis-api/batch-api/traffic-and-engagement) | Traffic/engagement estimates, scope device/geo/time | Paid entitlement/credits; cost проверить до запроса, нет покупки по умолчанию. [Methodology](https://support.similarweb.com/hc/en-us/articles/5083358615313-Similarweb-Data-Methodology-FAQs) — ограничения, не owner analytics |
| [SEC EDGAR](https://www.sec.gov/search-filings/edgar-application-programming-interfaces) | Company disclosures/submissions/XBRL | Public data без key. Fair access/User-Agent/rate rules: [SEC policy](https://www.sec.gov/filergroup/announcements-old/new-rate-control-limits), до 10 requests/s как верхняя граница; наши запросы ниже и с backoff. Не покрывает всех private firms |
| [Appfigures](https://docs.appfigures.com/api/reference/v2/estimates) | Mobile download/net revenue estimates | Product access/entitlement проверить, supported stores/countries; owner revenue reports и competitor estimates не смешивать |
| Official company IR/pricing/open dashboards | Business model, disclosed revenue, pricing | Read-only public research; разные billing/period/scope. Paywall/private exports только в разрешённом scope |

Перед каждым использованием: provider capability/status (`not_configured`, `available`, `denied`, `quota_limited`, `not_supported`) + actual tool/version/access_checked_at, dataset coverage/cost ceiling/rate/cache/retention. Статус available только после реальной успешной разрешённой операции, не по наличию документации или env name. Auth failure → stop этого источника/fallback; не retry бесконечно и не обходить ограничения.

Не просить credentials в чате, не писать values в URL/argv/logs/ADR. В target `.delivery/research/` — actual nonsecret provider config и secret-store reference при необходимости; в `.ai-development/product/` — rationale, access status и sanitized evidence. Неофициальный Trends scraper не default: нестабильность/доступ/terms нужно отдельно обосновать. Paid calls, account creation, установка connector/MCP требуют своего явного scope; текущая authoring-задача их не запускает.
