# Data sources and APIs: conditional access

Case-based methods are mandatory before tools: [case map](cases/README.md). Checked 2026-10-19; **this package connects no account/API**. Use actually available host connectors/tools or authorized web/manual exports; do not invent SDK endpoints. The catalog describes capabilities, not installed integrations.

| Provider / source | Data and applicability | Access / limitations / fallback |
|---|---|---|
| [Google Trends API alpha](https://developers.google.com/search/apis/trends) | Search interest, rolling 5y, consistent scaling, geography | Application/approval, not a publicly available API key. Verify actual access; otherwise Trends UI/export, explicitly recording the different measurement contract |
| [Trends UI](https://support.google.com/trends/answer/4365533?hl=en) | Relative sampled index | Export using available means; preserve query/window/geography/property. Do not convert index to buyers |
| [Google Ads Keyword Planning](https://developers.google.com/google-ads/api/docs/keyword-planning/overview) | Historical volume/competition/bid metrics; not others' spend | OAuth/account permissions and Cloud-project access, current API version; stricter quotas/cache. [Current access migration](https://developers.google.com/google-ads/api/docs/api-policy/developer-token): developer tokens sunset on 2026-09-09; do not copy old onboarding; check library compatibility. Without access use official exports/public research |
| [Meta Ad Library API](https://br-fr.facebook.com/ads/library/api/?source=onboarding) | Available archive, creatives/delivery; fields depend on category/region | At the checked date, all-type UK/EU for one year, worldwide political/social ads for seven years; auth/identity requirements. Political-ad spend ranges do not apply to all commercial ads. API scope differs from public UI |
| [TikTok Commercial Content API](https://developers.tiktok.com/products/commercial-content-api) | Advertiser/paid ads/selected commercial metadata | Application approval, client auth; current page indicates EU-only data and global requester eligibility. Ads up to one year after last shown. Do not promise a complete global archive |
| [TikTok Creative Center](https://ads.tiktok.com/business/library/NA_Creative_Center_Top_Ads_One_Pager.pdf) | Selected high-performing creatives, inspiration | Curated selection, not a census of all competitor ads, budget or guaranteed ROAS |
| [Google Ads Transparency](https://blog.google/innovation-and-ai/technology/ads/announcing-the-launch-of-the-new-Ads-Transparency-Center/) | Public advertiser/ad research | UI observation; a general public API is unconfirmed here; do not promise a ready collector |
| [Similarweb](https://docs.similarweb.com/api-v5/similarweb-api/website-analysis-api/batch-api/traffic-and-engagement) | Traffic/engagement estimates, device/geography/time scope | Paid entitlement/credits; verify cost before requests, no default purchase. [Methodology](https://support.similarweb.com/hc/en-us/articles/5083358615313-Similarweb-Data-Methodology-FAQs) describes limits, not owner analytics |
| [SEC EDGAR](https://www.sec.gov/search-filings/edgar-application-programming-interfaces) | Company disclosures/submissions/XBRL | Public data without a key. Fair-access/User-Agent/rate rules: [SEC policy](https://www.sec.gov/filergroup/announcements-old/new-rate-control-limits), up to 10 requests/s as a ceiling; our requests stay below with backoff. Not all private firms are covered |
| [Appfigures](https://docs.appfigures.com/api/reference/v2/estimates) | Mobile-download/net-revenue estimates | Verify product access/entitlement and supported stores/countries; do not mix owner revenue reports with competitor estimates |
| Official company IR/pricing/open dashboards | Business model, disclosed revenue, pricing | Read-only public research; different billing/period/scope. Paywalls/private exports only within authorized scope |

Before each use record provider capability/status (`not_configured`, `available`, `denied`, `quota_limited`, `not_supported`) + actual tool/version/access_checked_at, dataset coverage/cost ceiling/rate/cache/retention. Available requires an actual successful authorized operation, not documentation or an environment-variable name. Auth failure stops that source/uses a fallback; never retry indefinitely or bypass restrictions.

Do not request credentials in chat or put values in URLs/argv/logs/ADRs. Target `.delivery/research/` holds actual nonsecret provider configuration and secret-store references if needed; `.palarran/product/` holds rationale, access status and sanitized evidence. An unofficial Trends scraper is not the default: justify instability/access/terms separately. Paid calls, account creation and connector/MCP installation require their own explicit scope; this authoring task starts none.
