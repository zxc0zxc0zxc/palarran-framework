## Progress

TASK IDs grouped pending/in_progress/implemented/integrated/verified/blocked/deferred; exact remaining work and reasons/dependencies. Code-ready is not test-verified. Which revision of the plan is implemented, which deltas await decision.

## Execution and evidence

Owned agent/worktree/branch paths, lane commits/reports, integration order/retests and retained artifacts. Actual edge/invariant/DB/API checks with safe evidence; commands/runtime requirements without secrets.

Instrumentation/lab SLO/operational SLA window/RTO-RPO separately, thresholds/environment/current commit. DoD actual PASS/FAIL/NOT_RUN, no false full completion. Production deployment status separately.

## Resume

Next ready tasks and blockers, affected checks to rerun after code/source changes, owners and cleanup state. Preserve unintegrated/dirty work; inspect ledger/plan/Git/evidence before resuming, not prior agent claims alone.
