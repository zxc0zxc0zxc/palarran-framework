# Frontend handoff

- Task / target / implemented commit:
- Status: implemented | verified | partial/unverified
- Source UX/UI revisions and scope:
- Implemented routes/components/states and coverage link:
- Decisions: canonical IDs/links, reuse and reasons, proposed source deltas:

## Run and open

Exact project commands, actual local URL, environment prerequisites without secret values. App code/tests/assets paths; evidence directory. Dev process ownership/status.

## Verification

Build/lint/typecheck/tests PASS/FAIL/NOT RUN. Browser tool/version, actual viewports/scenarios, screenshots viewed, responsive/focus/console/network review. Distinguish fixture mode and real API/read-back. No unsupported all-browser, user-tested, accessibility certification or deployment claims.

## Remaining work and context

Missing assets/source/API/tool, concrete effect and next step; preserved revisions and target indexes. Following tasks read these records and verify current assumptions before reusing old PASS.

## SDD execution and resume

Implemented plan ID/revision + source UX/UI/API versions, integration commit, ledger/source plan section links. TASK IDs/counts by pending/in_progress/implemented/integrated/verified/blocked/deferred; exact remaining causes/dependencies and DoD gates. Agent/worktree/branch ownership, scoped commits/reports/integration checks and saved cleanup state. Before resume check actual source/Git/evidence and invalidate affected stale PASS, then continue remaining tasks.
