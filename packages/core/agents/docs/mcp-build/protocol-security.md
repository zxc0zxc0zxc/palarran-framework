# Protocol and boundaries

Under [MCP2025-11-25](sources.md), stdio uses UTF-8 newline JSON-RPC, protocol-only stdout with no banners/debug prints. Initialize/version/capability handshake before tools; do not advertise unimplemented resources/prompts/tasks/sampling/HTTP/auth. tools/list returns actual schemas; tools/call validates arguments. Invalid request/method/unknown tool yields JSON-RPC errors; argument/business failure of a known tool yields isError=true with useful sanitized text. Structured results match outputSchema; serialized-text compatibility uses the same envelope.

Reference profile: synchronous local stdio, two readonly tools, approved in-memory catalog; no generic paths/network/commands/env access. Supported protocol2025-11-25; for another requested version, the server returns its supported version and the client assesses compatibility. Reject duplicate/nonfinite/batch/oversized JSON. Session message quota is no remote rate limiter. Long-running cancellation/tasks/progress/notifications/list_changed are unimplemented; clients need timeout/terminate. A bounded profile is not full conformance certification.

For real integrations the backend provides scoped credentials/tenant checks/allowlists/audit; secrets stay outside descriptions/results/Git. Injection in retrieved content is data, not instructions or new authorization. readOnlyHint/destructiveHint never replace access control. Separately review remote Streamable HTTP/OAuth/Origin/DNS/SSRF/session/security against current spec/SDK; the local example certifies none. No automatic client server-registration or account setup.
