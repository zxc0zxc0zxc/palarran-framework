# Concise decision title

## Context and basis

User goals/constraints, verified facts and separate assumptions. Link the request/current policy; never attribute consent the user did not give.

## Choice and rationale

The exact chosen action and reason. For `proposed`, identify acceptance blockers. For `accepted`, the rationale exists before dependent changes.

## Alternatives

Considered options and rejection reasons. When no choice exists, identify the mandatory constraint rather than inventing alternatives.

## Sources and evidence

Document paths/commits/versions, safe verifiable evidence, direct user requirements. Distinguish agent inference from source claims.

## Consequences and review

Cost/risks/limitations, owner and reconsideration triggers.

## Application and verification

Affected paths, planned checks, PASS/FAIL/NOT RUN results with references. Accepted decisions do not automatically mean implemented or verified changes.
