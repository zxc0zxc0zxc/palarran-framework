# Scoped Git delivery

Contract v001, 2026-10-24. Read the [sharing contract](contract.md) first. Sources: [Git worktree](https://git-scm.com/docs/git-worktree), [commit](https://git-scm.com/docs/git-commit), [push](https://git-scm.com/docs/git-push) and [fetch](https://git-scm.com/docs/git-fetch). Git operations preserve the primary checkout; publication needs separate explicit confirmation.

`GitShare(repository)` accepts an existing trusted repository. `checkpoint(paths, worktree, branch, message, expected_head=...)` copies only fully owned regular files/deletions from that exact primary HEAD into a fresh owned worktree, stages explicit paths and creates a normal commit with hooks enabled. The source index and working files are never rewritten. Mixed-ownership files must first be split by the caller. Reviewed paths exclude private journals, credentials, symlinks and submodules. Commit hooks are trusted executable project code; they are not sandboxed. Failed hooks leave the owned worktree for review; never sweep their output into another commit.

`publish(sha, remote, branch, default_branch, intent_file, confirmed=True)` pushes an exact commit to a named configured remote and a non-default `codex/` branch. A private durable intent is written before push. Every later invocation reconciles the remote branch first; matching SHA means delivered, any other outcome stops as unknown/conflicting and never retries automatically. Use a fresh explicitly reviewed operation after operator reconciliation. Remote default HEAD is checked in addition to the required explicit default branch. This is not force-push or PR creation.

`receive(sha, remote, branch, worktree, local_branch)` uses the receiver's own Git access, fetches the offered branch, verifies its exact SHA, then creates a fresh owned worktree/branch. It never checks out, resets or stashes the primary checkout. An already existing worktree is rejected rather than replayed.

`bundle(selections, reviewed=True)` packages only explicit regular private files whose SHA-256 matches the reviewed map, at most 32 files/1 MiB total. The caller must perform privacy review; extension/path and obvious-secret checks are defense in depth, not a privacy proof. The returned JSON contains base64 bytes plus hashes; store/transmit only through the reviewed private channel, never Git or chat. No full journal import, credentials, auth files, raw logs or recursive directory selection. The helper does not restore a whole agent session, transfer external processes or establish business acceptance.

All subprocesses use literal argv, an explicit environment, no shell, process-group timeout and bounded output. Metadata commands disable fsmonitor; commit/push hooks stay enabled. Local disposable repositories exercise invariants; physical multi-machine and hosted provider delivery remain NOT_RUN.
