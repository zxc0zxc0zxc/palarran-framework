# Automatic parallelism

Palarran evaluates useful independent work for ordinary requests, every skill and each plan transition. Small or sequential tasks stay with one agent. [Contract](docs/contract.md) describes the shared dispatcher; [sources](docs/sources.md) records its basis. Temporal is optional; neither installation nor configuration grants execution authority.

The existing serial orchestrator remains compatible. This capability adds a separate durable dispatcher for parallel task manifests. Native desktop conversations use installed instructions; managed entrypoints can control only supported, observable adapters. Read actual integration status before relying on enforcement.
