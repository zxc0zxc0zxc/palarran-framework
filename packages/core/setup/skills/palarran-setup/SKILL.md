Existing installs with no preference changes can omit the selection flags.

Do not run carried project scripts during memory checks.
5. Inspect actual status; check memory initialize/list/search only when selected or required by a legacy receipt. Unselected memory is NOT_SELECTED and does not block setup. Filesystem completion and MEMORY_NOT_READY are separate; report the blocker and read-only doctor without replaying installation.
