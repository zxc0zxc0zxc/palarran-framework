# Security

Optional readonly audits with explicit coverage, evidence and retest steps. Core security protects framework execution; this package reviews target applications and infrastructure. Installing it grants no target access or remediation permission.

- [infrastructure](infrastructure/docs/README.md): `/palarran:security:infrastructure`.
- [ingress](ingress/docs/README.md): `/palarran:security:ingress`.
- [log](log/docs/README.md): `/palarran:security:log`.
- [egress](egress/docs/README.md): `/palarran:security:egress`.
- [code](code/docs/README.md): `/palarran:security:code`.
- [cve](cve/docs/README.md): `/palarran:security:cve`.

Start with the [shared contract](shared/docs/contract.md). Reports are private; missing checks stay NOT_RUN, never proof of safety. CVE research prefers available Keenable tools and verifies applicability against primary vendor advisories.
