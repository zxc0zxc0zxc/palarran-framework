The working official source above is **cisagov/kev-data**, whose README and schema were actually read. No current catalog entries or absence claims are copied into this guide.

[NVD developer documentation](https://nvd.nist.gov/developers/vulnerabilities) and [NVD data feeds](https://nvd.nist.gov/vuln/data-feeds) returned no usable page content in this authoring tool on 2026-10-24. Treat NVD details as an explicit retrieval gap; do not attribute range/API semantics to unseen pages. In a real audit, seek a working official NVD record/feed for the candidate and preserve its actual access/modified timestamps, or mark that lookup NOT_RUN. Third-party summaries are leads, not substitutes for authoritative applicability.

For every later advisory decision, record actual retrieval time, available publication/modified date, inventory version/hash, record revision/hash and source access gaps. Cached/missing timestamps remain explicit; this catalog's date does not certify freshness. Source-provided severity/exploitation claims and our contextual prioritization remain separate.
