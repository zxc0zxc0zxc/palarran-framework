# Suite v1

JSON <=1 MiB; duplicate keys, NaN, symlinks and escaping paths forbidden. Fields: version=1, id, revision, candidate (short IDs), limits, policy, cases; optional ai_policy/usage_policy follow existing runtime contracts. Cases 1..100: id, category (plan/build/review/context), task, checks. Task is a normal runtime task without id/verify/dependencies/retry fields; adapter command for fixtures or codex/claude with prompt/executable/model_role/model_calls. Runtime context/transport allowed. AI requires both policies; no default cash allowance. Cases execute sequentially without retry. limits.max_attempts must be 1.

Checks 1..20:

- json_equals: kind, path (target-relative regular JSON <=64 KiB), expected (JSON value); strict type comparison, bool is not number. Explicitly include format/path in task prompt.
- command: kind, argv (explicit absolute allowlisted executable), pins (nonempty list of absolute external regular files). Pin every grader interpreter script/fixture/config/resource. argv is not shell; {workspace} resolves to the exact owned worktree. Pins cannot be inside target/state candidate workspace. Scripts/fixtures must be self-contained; unpinned verifier dependencies are a trusted-configuration limitation.

Create normalizes the manifest, hashes pins/harness source and stores a private bundle outside the worktree; generated verifier argv includes bundle SHA. Runtime workflow snapshot freezes argv and budget. Bundle/checker drift fails closed. Do not read .env/credentials/raw logs as eval input. Public reports contain metrics/hashes, not prompts/expected answers/stdout. Report-time drift is rejected with a safe error and cannot count as PASS. The private bundle contains the rubric and must never be committed.

Report reads only the bound run and checks workflow digest, suite/pin/harness hashes, final subject and usage completeness; JSON-output hashes are compared with stable receipts even for Git-ignored answers without rerunning command graders. Separate quality_verdict reflects final checks; overall verdict additionally requires complete financial accounting. Historical unknown carry does not invalidate proven quality but forbids complete-cost/savings claims. Show cases, attempts/measured seconds, runtime reason, PASS/FAIL/INCONCLUSIVE/NOT_RUN, pass_count/total_cases/coverage, cumulative usage including carry and observed lower bounds. A suite missing final verification cannot PASS. Command-only sample_kind=fixture, tokens/cost=null (no model measurement); zero spending does not prove model efficiency.

Compare requires identical protocol_sha256 (inputs/prompts/graders/limits/pricing and token budgets), harness hash, baseline, environment and actually supplied context; candidate label and assigned model/effort/executable may differ. Comparing one run with itself is forbidden. Incomplete/fixture runs establish no model-cost savings. Changing a skill prompt creates a new protocol, requiring manual comparison with explicit differences. Automatic routing and paid judges are outside v1.
