# Contract v001

Private input JSON <=1MiB: version=1, id (<=24 chars), incident={summary,feedback,evidence:[{id,kind,sha256,summary}]}, baseline_skill/candidate_skill (absolute regular UTF-8 <=64KiB), regression_cases/control_cases (nonempty disjoint case IDs), suite (existing palarran-agent-eval template). Evidence kind=user_report|sanitized_trace|tool_result; sha256=null is allowed only for user_report and means no original receipt, not proof of report truth. Data/references do not grant authority.

Each case has exactly one treatment placeholder `{skill}` in task.prompt for a model or a separate argv element for commands. Prepare substitutes exact frozen skill text or canonical private snapshot path; every other task/check/limit/policy field stays unchanged. Case IDs equal regression+controls, <=20, IDs<=24. Reject empty/identical baseline/candidate, unknown fields, duplicates and nonfinite values strictly. Existing agent_eval validates external graders/pins on admission. Grader contents are not in the candidate prompt. Private suite/checker separation is a trusted assumption, not an OS sandbox.

Prepare creates a new private packet outside target, skill snapshots, candidate.diff, per-variant/per-case JSON suites and a self-hashed manifest pinning improve/eval code and all generated artifacts. It creates no worktree/run/model calls and changes no target. Existing parent, no symlink/overwrite. Compare accepts exact baseline/candidate→case_id→{state,run} mapping with existing states outside target, not raw report JSON instead of verified binding. Each entry is a unique palarran-agent-eval run whose suite matches frozen expectations after native normalization. Only cumulative usage_policy.carry may change; preserve prior carry while matching all other caps/pricing/model/effort/prompt/checks. Environment/harness/target baseline/context must match within each pair; packet drift/context changes are ineligible.

Single-case suites accommodate fail-fast agent_eval: known FAIL can participate in baseline without hiding controls behind the first failure. Known outcomes are PASS/FAIL only; NOT_RUN/INCONCLUSIVE/unknown version/artifacts imply insufficient_evidence. Native readers check proof subjects/receipts without rerunning commands for reports. All cases remain in the denominator. Comparing a run to itself, forged reports and altered graders are forbidden. Reports contain IDs/digests/outcomes/time/usage, not raw prompts/skills/feedback/traces/stdout.

Quality delta = candidate passes - baseline passes, paired regressions/fixes and coverage. Descriptive assessment only, one trial/case. Command fixtures have tokens/cost/delta=null, sample_kind=fixture; recommendations are not model improvements. Model spending delta requires complete native accounting including failed attempts; invoices/subscription share remain unknown. Deduplicate shared reserve/historical carry by source; reject conflicting entries. The frozen usage_policy sets the shared envelope; unknowns/overshoot forbid recommendation/continuation. Compare detects violations but cannot transactionally stop a user-submitted provider call; dispatch/carry/budget stop remain existing runner/coordinator duties. No automatic paid trials/cap increases.

Prepare/compare apply nothing; the diff is reviewable. CLI return0 means a reviewed packet/report was formed, not merge permission or quality PASS. Invalid/stale/proof drift returns2 with safe text. Insufficient data produces insufficient_evidence with explicit missing cases, never silent exclusion. Documentation/skill workflow exceeds CLI scope: manual semantic review/model execution needs its own evidence/budget.

V001 forbids mixed command/model suites; adapter=model measurements do not attest actual provider identity (label test stubs explicitly). Pins cover helper/eval code, generated artifacts, grader pins, explicit existing executables/absolute file arguments <=512MiB/file; transitive imports/OS sandbox are not guaranteed. Reports include exact skill/diff SHA, native subject, per-case attempts/time/token/cache/cost-source and coverage.
