# Suite v1 and verdict

Private JSON <=1MiB, strict duplicate/nonfinite/unknown-field rejection. Root fields: version=1,id,target,revision,source_files,base_url,identity={path,pointer},effects (list declared test mutations),limits={run_seconds,step_seconds,max_response_bytes,max_artifact_bytes},browser (null or {node,module,executable}),cases. Base URL v1 loopback HTTP only, no userinfo/query/fragment; remote targets through separately scoped manual tools, not this CLI.

Case: id,requirements (R-ID list),given,when,then,not_applicable (browser/api/db→reason),steps. All three surfaces required except explicit N/A; omitted surfaces are NOT_RUN. API step: method GET|POST|PUT|PATCH|DELETE,path,status,pointer,expected, optional body. DB step: path,table,columns,where,expected (ordered rows). Browser step: actions list,viewport={width,height},screenshot bool. Browser actions goto(path),fill(locator,value),click(locator),press(locator,key),reload,expect_text(locator,value),expect_visible(locator). Locator has exactly one of role+name, label or test_id. Relative paths cannot change origin. String placeholder {run_id} expands to random run ID + case ID (entity_id in report), shared across browser/API/DB in the scenario. Correlation is mandatory in browser goto/fill, API path/body and DB where; placeholder only in expected is insufficient. This structural gate does not replace reviewer checks of business predicates. No credentials in suite; v1 automatic authentication import/env headers unsupported; use disposable test apps/users with separately reviewed tool workflows when required.

Limits: run 1..600s, step 1..60s <=run, response1KiB..1MiB, total artifacts1KiB..16MiB; <=50 cases, 1..100 steps/case, <=100 steps total, <=100 browser actions/step. DB table/column identifiers are constrained and checked against actual table schema; SQLite integer range checked, bound values, rows <=1000, bounded query deadline; no arbitrary SQL, views, writes/cleanup. DB path is a canonical regular file; mutable DB excluded from source_files. Expected rows ordered by declared columns; explicit SQL null semantics. SQLite adapter only in v1.

create validates/hashes local inputs/driver/browser executable/module entry + sibling test.js/package.json and saves frozen bundle outside target without app/network/DB/browser execution. run creates durable single-attempt intent before any action; repeated run rejected, no replay. Every step stores typed result/time/predicate evidence; raw response/DB values/console/stderr not reported. Assertions FAIL; tool unavailable/network/timeout/version drift/artifact corruption INCONCLUSIVE; dependent or unsupported coverage NOT_RUN; explicit N/A stays visible. Mutation timeout outcome unknown; no retry; reconcile test fixtures before new run.

Final recheck source/driver pins + live revision endpoint, then seal artifact hashes and report.json/report.md. Overall FAIL if any mismatch, otherwise INCONCLUSIVE if missing/unknown/stale, otherwise PASS in declared scope. report reads only local bound artifacts, checks hashes/source pins, no app calls; it cannot promise deployment freshness after the recorded run. One-attempt state after coordinator loss reports incomplete; does not dispatch actions. Exit 0 PASS, 1 FAIL, 2 INCONCLUSIVE/rejected input. No model/cash ledger fabricated: model_calls=0, provider cost=null/not_applicable, no free production cost claim.

No automatic visual approval: captured PNG is evidence, visual_review=NOT_RUN unless separately reviewed. The v1 CLI does not itself certify arbitrary requirement semantics or independent authorship. Freeze schema and criteria before execution; edits require new revision/run/fixture review.

Pins do not cover the entire transitive Node/browser dependency closure or prove hostile-code isolation. Frozen wall/step limits include observed elapsed time; browser termination has up to 4s grace, not a hard real-time deadline. Incomplete-bundle recovery conservatively marks unknown effects; report does not resume execution.

Local integrity preflight/hashing is separate from step timing: <=200 declared source files, <=512MiB/pinned file plus bounded driver/runtime pins. This trusted bounded runner is not an OS-enforced CPU/memory/time sandbox. Exclude datasets/binary outputs from source_files; larger deployments need a domain release manifest.
