## Run and open

Exact project commands, actual local URL, environment prerequisites without secret values. App code/tests/assets paths; evidence directory. Dev process ownership/status.

## Verification

Build/lint/typecheck/tests PASS/FAIL/NOT RUN. Browser tool/version, actual viewports/scenarios, screenshots viewed, responsive/focus/console/network review. Distinguish fixture mode and real API/read-back. No unsupported all-browser, user-tested, accessibility certification or deployment claims.

## Remaining work and context

Missing assets/source/API/tool, concrete effect and next step; preserved revisions and target indexes. Following tasks read these records and verify current assumptions before reusing old PASS.
