# R1 — Название продукта

Статус карточки: draft; пример структуры, не доказательство проведённого исследования.

## Relevance

Категория/primary job, прямая или adjacent аналогия, рынок/аудитория и причина выбора. Если популярность влияет на вывод — источник/дата; без ранга не писать «лидер рынка».

## Scope и provenance

- Source page URL, author/publisher и publication/update date (unknown, если нет).
- Accessed at: дата фактического просмотра.
- Platform/locale/viewport/role/version: известное и unknown отдельно.
- Method: live-observed / official-documented / screenshot-observed / inferred / not-observed.
- Кабинет: доступен / official tour / screenshot source / not observed; выполненный поиск и gaps.
- Safe evidence file или доступная source link; video timestamp при использовании кадра. Auth query strings/personal data исключены.

## Что переносим и что отвергаем

Для каждого паттерна: business need → observation → наша адаптация → Screen/Block/State → ADR. Не переносить визуальный стиль/брендинг. Не утверждать keyboard/ошибки/скрытый переход по одному screenshot.
